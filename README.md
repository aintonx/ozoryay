# Удаление карты и истории деплоя

## Сначала — короткое уточнение по факту

Leaflet (библиотека, на которой строилась карта) — правда написана
украинским разработчиком (Владимиром Агафонкиным). Но техническая сторона:
это open-source код с открытой лицензией MIT, весь исходный код публичный
на GitHub, его использует огромное количество сайтов по всему миру, включая
крупные компании из самых разных стран — если бы в коде было что-то
недоброжелательное к какой-либо стране, это было бы видно любому, кто
откроет исходники, и давно стало бы известно. Личные политические взгляды
автора не попадают в код таким образом, который мог бы что-то делать
в зависимости от страны пользователя сайта — библиотека просто рисует
карту, ничего не проверяя и никуда не «звоня» на основе гражданства.

Это не значит, что тебе нужно её оставлять — сайт твой, решение полностью
за тобой. Просто хотел, чтобы решение принималось на основе точной картины,
а не наоборот. Ниже — как убрать её полностью.

## 1. Удаление кода карты

В архиве — **весь `src/` из самой первой, ещё докарточной версии
репозитория** (я сохранял её у себя с самого начала, до всех правок).
Ни одного упоминания leaflet или map в ней нет — проверил командой
`grep -ril leaflet` по всему дереву, ноль совпадений.

Как применить:
1. Замени папку `src/` в репозитории целиком этой.
2. Замени `package.json` и `package-lock.json` — в них тоже убраны
   `leaflet`, `react-leaflet`, `@types/leaflet`.
3. `git add -A`, `git commit -m "убрать карту"`, `git push`.

После этого в рабочем дереве и в коде, который уйдёт в деплой, карты не
будет вообще — ни строчки.

## 2. Удаление истории деплоя (упавшие запуски в Actions)

GitHub → твой репозиторий → вкладка **Actions** → зайди в упавший запуск
(или в успешный, если он всё же прошёл) → в правом верхнем углу «...»
→ **Delete workflow run**. Так удаляются логи конкретного запуска сборки.
Повторить для каждого запуска, что хочешь убрать.

## 3. Удаление коммитов с картой из истории git

Это уже не про деплой, а про сам git-журнал репозитория — если хочешь,
чтобы в `git log` тоже не осталось следов:

```bash
git log --oneline
```

Найди хэш коммита **прямо перед** тем, где начались правки про карту
(тот, что был последним, когда всё ещё нормально работало без неё), и:

```bash
git reset --hard <хэш_того_коммита>
git push --force
```

Это перезапишет историю на GitHub так, будто коммитов с картой не было
вообще. Важное предупреждение: `--force` перезаписывает удалённую историю
безвозвратно — если после этих коммитов было что-то ещё, что хочешь
сохранить, не делай reset до них. Если не уверен, какой хэш нужен — пришли
мне вывод `git log --oneline`, помогу найти точку.
