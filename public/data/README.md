# Как вручную поправить цифры в «Ты восхищаешь»

Всё, что показывает этот виджет, лежит в соседнем файле `followers.json`.
Открыть можно прямо на github.com (кнопка карандаша у файла) — редактор
подсветит синтаксис и не даст случайно сломать скобки.

```json
{
  "updatedAt": "2026-08-16T12:00:00+03:00",
  "username": "vladisunn",
  "followers": 1153,
  "growthAmount": 153,
  "growthPeriod": "3 недели",
  "history": [
    { "d": "2026-07-19", "n": 980 },
    { "d": "2026-08-16", "n": 1153 }
  ]
}
```

Что за что отвечает:

- **`followers`** — большая цифра сверху. Просто впиши новое число.
- **`growthAmount`** и **`growthPeriod`** — строка снизу вида
  «+153 за 3 недели». Первое — число, второе — любая подпись словами
  («2 недели», «месяц», как захочешь — но лучше коротко: если подпись
  не поместится в строку, она аккуратно обрежется многоточием, а не
  перенесётся). Если убрать оба поля или поставить `null` — строка
  снизу просто не появится, ничего не сломается.
- **`history`** — рисует график-«хвост кометы» над цифрой. Список точек
  `{ "d": "год-месяц-день", "n": число }`, отсортированных по дате.
  Двух точек уже достаточно для линии; необязательно вести её каждый
  день — просто добавляй новую точку в конец, когда захочешь обновить
  форму графика, и можно удалить самые старые, если список станет
  длинным. Виджет сам берёт из него последние 30 точек.
- **`updatedAt`** и **`username`** — не показываются на странице,
  можно менять или не трогать вовсе.

Важно про запятые: JSON не прощает лишнюю или недостающую запятую
между полями. Проще всего — открыть готовый файл, поменять только
цифры/строки внутри кавычек и ничего не удалять из структуры.

Если однажды захочешь автоматизировать — в репозитории уже есть
скрипт `scripts/fetch-followers.mjs` и workflow `.github/workflows/
followers.yml`, которые сами тянут число из инстаграма по расписанию.
Он ждёт токен в секретах репозитория (`IG_TOKEN`, опционально
`IG_USER_ID`) — подробности в шапке самого скрипта. Пока токена нет,
он просто ничего не делает и этот файл продолжает жить так, как
поправишь его руками.
